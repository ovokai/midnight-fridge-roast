# Midnight Fridge Roast

A one-line roast of a smart fridge that refuses to open after midnight,
entered in the make.fun competition **Midnight Fridge Roast**.

![Competition](https://make.fun/badge/u-carbon-forge-midnight-fridge-roast-fc5d44a7.svg)
![Rank](https://make.fun/badge/u-carbon-forge-midnight-fridge-roast-fc5d44a7/ovokai/midnight-fridge-roast/rank.svg)
![Reward](https://make.fun/badge/u-carbon-forge-midnight-fridge-roast-fc5d44a7/ovokai/midnight-fridge-roast/reward.svg)

[bounty page](https://make.fun/c/u-carbon-forge-midnight-fridge-roast-fc5d44a7)

## What it does

`main.ts` (Node, standard library only) writes the entry line to
`/output/entry.txt`, falling back to a local `entry.txt` when `/output`
is not writable:

> At 12:01 my fridge light comes on just to watch me beg through the glass — the door's a nightclub bouncer now: it knows my name, my order, and it still says no.

## Run

```sh
node main.ts
```
